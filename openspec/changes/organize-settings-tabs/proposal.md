## Why

设置窗口目前将通用选项、窗口位置预设、硬件监控阈值和 LED 灯效全部放在同一个长页面中，内容增长后查找和操作成本较高。增加左侧标签页导航并按用途分组，可以缩短页面、提升设置项的可发现性，同时保留现有配置行为。

## What Changes

- 将设置窗口改为左侧标签页导航布局。
- 将现有设置分为“通用”“窗口位置”“硬件监控”“LED 灯效”四个标签页，并增加“关于”标签页。
- 将开机自启动和窗口置顶放入“通用”。
- 将窗口坐标、当前位置捕获和位置预设管理放入“窗口位置”。
- 将硬件轮询间隔、CPU/GPU 温度上限及使用率/温度颜色阈值放入“硬件监控”。
- 将默认灯效模式和空闲恢复时间放入“LED 灯效”。
- 在“关于”中显示当前程序版本、GitHub Releases 超链接、作者 GitHub Profile 超链接、技术栈和开源组件信息。
- 在“关于”中增加检查更新按钮：检查 GitHub 最新 Release，发现新版本时提醒用户并打开 Release 页面；已是最新版本时提示无需更新。
- 保持现有“应用”“保存”、取消关闭、输入校验、位置预设即时保存及配置字段不变。
- 适当调整窗口尺寸和内容滚动范围，使每个标签页内容可独立浏览。

## Capabilities

### New Capabilities

- `settings-navigation`: 提供设置窗口的左侧标签页导航与按用途分组的设置内容，确保用户可以在各组之间切换并继续使用现有设置操作。
- `about-and-update`: 提供当前版本、项目/作者链接、技术栈与开源组件信息，以及基于 GitHub Release 的手动更新检查。

### Modified Capabilities

无。此次变更只调整设置窗口的信息架构和呈现方式，不改变现有配置项的语义或持久化要求。

## Impact

- 主要影响 `src/MagicCenterHub/SettingsWindow.xaml` 的布局和控件分组。
- 可能需要少量调整 `src/MagicCenterHub/SettingsWindow.xaml.cs`，仅用于适配标签页初始化或保持现有控件事件行为。
- 不修改 `Settings` 模型、配置文件格式、保存服务或主窗口业务逻辑；更新检查使用 .NET 现有网络和 JSON 能力，不新增第三方依赖。
- 需要补充设置窗口布局和关键操作的验证，重点确认跨标签页编辑后“应用/保存”仍保存全部字段。
